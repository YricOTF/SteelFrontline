# 钢铁前线 · Steel Frontline

以登陆、增援、战术编队和据点争夺为核心的浏览器即时战略游戏。攻方需要控制大本营及至少一半可用的外围据点。守方坚守至倒计时结束即可获胜。

## 运行

GitHub Pages 入口位于仓库根目录的 `index.html`。本地可从仓库根目录启动静态服务器：

```sh
python3 -m http.server 8000
```

打开 [http://localhost:8000](http://localhost:8000)。单人战役和新兵训练的素材与脚本均随仓库提供。多人支持房间码和手动 P2P，使用 WebRTC 数据通道。房间码模式会在连接时加载 MQTT 信令库。

## 战役规则

- **前线模拟**为新单人战役的默认规则。移动和射击消耗补给，登陆场和已可用的己方据点提供补给。道路和桥梁可扩大补给范围。选中部队后按 **R** 或点击右侧补给按钮，命令部队向可达的补给点后撤。
- 受击与近距离爆炸会施加压制，降低单位的机动、射击和占点能力。掩体和驻守可加快恢复。烟幕可暂时阻挡直射火力，侦察机仍可提供观察。
- 单人可选 **经典攻防**。该规则也用于多人对战和新兵训练。单人战役时长可设为 15、25 或 35 分钟。
- 小地图支持点击和拖动定位。电脑端可用 **WASD** 平移、滚轮缩放、**Shift** 拖框选中、**Ctrl+A** 全选、右键下令、**Shift+数字** 编队、**P** 打开战术计划。触屏支持拖动、捏合缩放和长按指令。

## 存档

存档保存在当前浏览器。v24 存档可恢复原有的单位和据点进度。新存档还记录编队、地图种子和地形变化、技能进度、补给、压制及战损。

## 仓库结构

- `index.html` 包含菜单和战斗界面。
- `css/game.css` 包含桌面和触屏布局。
- `js/` 按地图、寻路、战斗模拟、人工智能、计划、渲染、音频、输入、界面、联机和存档拆分。HTML 通过 `defer` 按依赖顺序加载这些脚本。
- `assets/river-valley.webp` 是为主菜单生成的河谷插图。地形纹理由 Canvas 绘制，声音由 Web Audio 合成。

## 战场与事件

战役预览列出主要通路及地图大事件。地图采用种子生成地表细节，登陆场、据点和关键路线固定。桥梁适合快速机动，浅滩可以分担渡河压力。

| 战场 | 主要通路 | 大事件 |
| --- | --- | --- |
| 翡翠群岛 | 双侧鞍道与环岸公路 | 火山喷发 |
| 赤石山谷 | 双侧隘口与谷底横路 | 山谷落石 |
| 黑森林平原 | 中央农道、林带与桥滩 | 林带山火 |
| 断壁残城 | 南北大道、老城巷道与工业外环 | 储油区事故 |
| 怒涛渡口 | 三座桥和一处下游浅滩 | 上游涨水 |
| 大陆战场 | 三处登陆场与五处跨河通路 | 河谷风暴 |

事件经过预警、影响和解除三个阶段。点战场提示可定位，地图斜线和内圈分别表示影响区与伤害区。道路和桥梁继续承担机动功能，部分事件结束后会留下可穿行的瓦砾或焦痕。储油区受到爆炸波及时会提前预警。

新版地图和大事件从新战役启用。旧存档按原始地图布局恢复。旧版玩家加入时，房主使用双方都支持的地图布局。

可用 `node --test` 检查地图连通性和事件流程。
