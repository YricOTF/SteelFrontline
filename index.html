操 作 说 明

视角 — 单指拖动；双指捏合缩放。PC：WASD平移、空格定位、滚轮缩放。

选择 — 单击单位；长按空地350ms拖动框选；双击选中同类型；Shift多选；Ctrl+A全选。

长按单位 — 战术轮盘：移动/攻击/驻守/停止/回收。右侧常驻回收按钮也可用。

PC快捷键 — Q技能 / H驻守 / S停止 / P计划 / ESC取消 / 1-9编队 / Ctrl+A全选 / 空格居中。

计划侧栏 — 绘制：前线、区域防卫、线性防卫、进攻（基于已有前线）。

部署 — 点击兵种卡片后，在己方橙色部署点圈内任意位置点击。

多人 — 房主和客户端选相同后端。客户端进战场后需等"战场同步完成"。

本地测试建议 — 使用 HTTP 服务器打开（不要 file:// 双击），例如 python -m http.server 8000，再访问 http://localhost:8000/文件名.html

时长 — 25分钟。守方坚守即胜。
